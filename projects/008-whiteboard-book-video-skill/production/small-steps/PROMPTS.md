# 图片生成记录

工具：内置 imagegen；2026-09-06。首图独立生成，后六图均以首图作为参考编辑。以下是生成要求的中文归档摘要，而非库自带素材。上游贡献为 image-prompt.md 的视觉规范；图片内容由执行者按本次想法设计。

共同要求：竖屏白色网格白板，黑色手绘外框，黑红蓝记号笔，中文文字清楚，戴眼镜、红领结的小火柴人老师；充足留白，底部为字幕预留空间。保留首图的网格、画框、人物与配色。

1. **目标太大，迟迟没开始**：书本构成高楼梯，小人犹豫。文字“想读完一本书”“还没翻开第一页”。
2. **把第一步，缩小一点**：厚书“读完一本书”通过箭头连接打开的书“今晚只读两页”，红圈突出小动作。
3. **把行动，说得更具体**：月亮时钟“今晚”→桌子“坐到桌前”→书“读两页”，小人坐下阅读。
4. **让开始，少一道阻力**：上下对照，柜中书“开始前还要准备”，桌上书“提前放在桌上”。
5. **做完一步，留下记录**：书“读两页”→便签“记下一句话”；小人写字，复选框“记录这次完成”。
6. **小动作，不是万能答案**：蓝色循环箭头连接“先试一次”“观察效果”“按情况调整”，小人思考，“方法可以调整”。
7. **今天，先开始哪一步**：低矮三级台阶，小人站在红圈第一步；“今晚”“两页”“一句话”，收尾“先开始，再前进”。

结果：7 张 PNG，实际 941×1672。渲染为 1080×1920。图片已逐张观察；最终字幕遮挡情况以视频抽帧为准。
