为每个研究项目增加一段视频导读

先看约一分钟视频，理解问题与价值，再读完整文档。可以制作项目介绍片、机制解释片和场景演示片，例如 002 的长内容分块机制。批量生产还需新增内容模板、素材缓存、局部重做和任务管理。

选择原则：解释为什么、是什么、怎样理解，适合白板视频；精确软件操作、真实外观和人物动作，需要录屏、实拍或其他动画工具。

验证范围：目前只完成“小动作开始”有声案例；其他场景是基于实现的适配判断，尚未逐项制作。

05 / WHAT COMES NEXT

从经验流程，走向可复用的系统。

我们的扩展建议 · 尚未实现
01
优先 / 降低返工

结构化分镜 + 阶段缓存

将口播、图像、字幕与时间轴关联到同一镜头 ID。修改一句话，只重新制作受影响的素材。

先把流程做稳
02
优先 / 提升可控性

中文独立排版 + 字幕校正

插画交给模型，文字交给 HTML/SVG；用原稿校对 ASR，检查断句、溢出与时间重叠。

再把表达做准
03
后续 / 系列化生产

服务适配 + 视觉模板

替换图像和语音供应商，固定角色、色彩与布局，再逐步扩展多语言、多画幅与元素动画。

最后扩大产出
