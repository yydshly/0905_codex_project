## 安装与加载

上游给出的 Claude Code 安装方式是在其 skills 目录克隆仓库，然后重启宿主。Windows PowerShell 的等价写法如下；这是使用说明，本轮没有执行安装：

```powershell
$skillTarget = Join-Path $env:USERPROFILE '.claude/skills/mono-color'
git clone https://github.com/yanliudesign/mono-color-skill.git $skillTarget
git -C $skillTarget checkout c8ff70597ddedcd65f21a0b528f6a70c35690b0a
```

目标目录应为新目录。若已安装，先确认现有版本和本地修改，不覆盖已有内容。上面的 checkout 用于复现本研究版本；使用更新版本前应重新核对目录与规则。

其他 Agent 应按各自的 Skill 加载方式指定 `SKILL.md`，并保持 `design-system/` 等关联目录可读。安装说明不代表所有宿主的自动触发、图片输入和出图工具已经实测兼容。

原版写有 `~/Desktop/Claude skills/mono-color/` 的默认输出路径；实际使用前应在请求中明确目标目录，并让宿主按自身文件交付能力保存。仅安装规则不会自动增加图像生成工具。

## 请求怎么写

| 字段 | 推荐说明方式 |
| --- | --- |
| 用途 | 研究封面、活动海报、播客封面、观察笔记等 |
| 主体与意图 | 一个明确主体，加一句要表达的意思 |
| 准确文字 | 逐字给出标题、日期等，不让模型自行改写 |
| 配色 | 明确单墨或双色；优先选已有目录覆盖的方案 |
| 比例 | 明确 `3:4`、`1:1` 等需求，避免事后简单裁切 |
| 照片要求 | 忠实保留身份，或提炼哪些识别特征 |
| 风格方向 | 当代、复古或触感强度；不要只写“高级” |
| 交付 | 图片、最终提示词、配方；或明确“只给提示词” |

未指定时，原版默认竖版 `3:4`、当代编辑方向、受控双色，并默认自行创作英文短文案。用户提供的准确文字应保留原语言。使用中文标题时尤其需要检查最终图片，而不能只检查提示词里是否写对。

## 四种使用示例

### 1. 先看提示词和设计决策

```text
只给提示词，不生成图片。
用 mono-color 为“开源项目研究”设计一张 3:4 封面。
标题准确使用“开源项目研究”，使用钴蓝单墨、中性白底。
用一本展开的笔记本作为主体，保留一个明显焦点和安静留白。
不要添加组织名称、网址或虚构数据。
附上设计配方，并说明为什么选择该构图。
```

适合先检查文字、色版职责与构图理由。提示词合理仍不能证明图像模型能准确执行。

### 2. 生成活动海报

```text
用 mono-color 制作 3:4 读书会海报，使用钴蓝和陶土橙。
准确标题：“一起读一本书”。
日期：“2026年9月20日”；地点：“示例书屋”。
这些是虚构练习活动的信息，仅用于设计练习。
采用当代编辑设计，书页作为主视觉，日期与地点保持清晰。
不增加赞助商、标志、网址或其他活动事实。
交付图片、实际提示词和配方；若文字重试后仍错误，说明问题并交付少文字底图。
```

此例中的活动信息为明确标记的虚构练习数据。真实使用时替换为确认过的信息，并逐字检查文字、数字和标点。

### 3. 保留照片内容进行改编

先通过宿主提供照片，再发送：

```text
把我提供的照片做成 1:1 播客封面，使用茄紫单墨。
准确标题为“慢慢说”。
忠实保留人物身份、表情与主要姿态，通过裁切和网点改变视觉呈现。
不要新增品牌信息，不要复制其他封面的排版。
交付图片、实际提示词和配方。
```

若目标是抽象表达，可改成“保留眼镜轮廓、头发形状和侧脸朝向三个识别特征，以形状与轮廓重新表达”。这是另一种表现策略，不能同时期待完全忠实的摄影细节。

### 4. 尝试系列封面

```text
为“材料来源”“内容处理”“阅读应用”分别设计一张 3:4 封面。
标题逐字保留，统一使用钴蓝和陶土橙，采用当代编辑方向。
共享纸色、标题区域和辅助信息层级，主体分别采用书架、纸页、打开的书。
每张只有一个视觉焦点。
逐张交付图片、实际提示词与配方，记录哪些参数共享、哪些参数改变。
```

系列方向符合规则复用思路，但仓库没有通用批量任务队列、版本管理或一致性自动评分。宿主可能逐张执行；本例不代表已经具备这些工程能力。

## 检查交付结果

1. 检查标题、日期、地点、数字是否逐字正确，是否出现额外品牌或事实。
2. 对照源照片，检查人物身份、物件特征和必要关系。
3. 在缩略图下确认主焦点清楚，安静区域没有被次要装饰填满。
4. 检查两种墨是否有明确职责；纸色、网点浓淡和叠印混色不应机械地当作额外色版。
5. 将图片与实际使用的提示词、配方和模型版本一起保存，记录重试原因。

原版要求检查失败时重试一次；准确文字仍出错时，改为少文字底图并说明需要外部排版。这不等于已经自动完成中文叠字。
