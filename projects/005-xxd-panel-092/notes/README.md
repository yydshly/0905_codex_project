# 源码研究与验证记录

日期：2026-09-05。上游版本：`9e86434703fe8eeccac2b6055900716c8eda4ee6`。

## 核心结论

项目是以固定风格提示词为核心的 Agent 工作流。没有本地线描模型或训练代码；图像理解和视觉重构由外部模型完成。它的可借鉴处是风格原文、交付适配、执行通道与验收职责的划分。

| 证据 | 观察 | 对使用的影响 |
| --- | --- | --- |
| references/original-prompt/zh-CN.md | 原始容器为 3:4 上下等分；强调轮廓、排线、负形 | 审美要求需完整保留，不能只抽几个关键词替代 |
| references/xxd-panel-092-prompt.zh-CN.md | 运行适配追加模式、画幅、文字 | 新模式替换旧容器，不默认等分 |
| SKILL.md | 目录批量、隔离、验收、重试主要写为执行规范 | 依赖 Agent 遵守，不是持久化批处理程序 |
| scripts/configured_imagegen.py | 通过兼容 images/generations 与 images/edits 请求图像 | 文档列出的模型未必均有独立适配 |
| probe() | 200 / 400 / 409 / 422 被判就绪 | 不足以证明真实参考图编辑可用 |
| write_png() | 尺寸不同时执行 ImageOps.fit | 可能裁切，不是无条件无损尺寸校准 |
| scripts/compose_panel.py | 位图拼接、缩放、分界分析 | 不能代替风格或中文准确性验收 |
| scripts/panel_preferences.py | 保存允许字段，排除图片、精确文案与凭据 | 交付偏好可以跨任务复用，内容应隔离 |
| assets/examples/README.md | 样张为完整画布生成扩展 | 不能当作本地实测，亦不能独立证明原图保真 |

上述路径均位于 [固定提交](https://github.com/nevertoday/xxd-panel-092/tree/9e86434703fe8eeccac2b6055900716c8eda4ee6)。

## 本次新增实现

- 原创静态中文研究界面；模式示意为 CSS 图解，明确标注非生成结果。
- 可交互任务配置：尺寸归一化、组合数量、普通模式与壁纸分支、准确文案、输入校验。
- 任务单 Markdown 下载、复制反馈、CSV 评测模板。
- 固定提交来源链接与完整上游素材许可。

首轮没有复制或执行上游 Python 程序，没有安装 Skill 或连接图像模型。原始提示词和两张样张按来源引用。

后续补充：增加两次内置 ImageGen 创意实验，使用独立文字提示词生成两张六格效果图。第一张展示钢笔内部扩展，第二张展示其他视觉表达；没有运行上游 Skill，也没有把上游样张作为参考输入。详见 `creative-atlas-prompt.txt`、`medium-atlas-prompt.txt` 与素材来源说明。钢笔图鉴提供六条独立创作要求，可在浏览器切换与复制；跨风格图鉴提供对应场景和交付边界。

新增图鉴浏览器检查：编号切换能够更新创意名称、场景与任务说明；复制按钮显示成功反馈。窄屏下图鉴和说明按单列排列；原图可以单独打开查看。两张图均已视觉检查，并保留完整生成提示词。

## 验证范围

- Node 内置测试：单张任务、混合模式批量数量、仅壁纸、等价尺寸去重、无效输入、准确文案与独立壁纸。
- JavaScript 语法检查。
- 总仓库项目元数据校验、静态构建和本地资源链接检查。
- 浏览器实测：桌面首屏与配置区、390×844 窄屏排版，无页面横向溢出；四步流程切换成功。
- 交互实测：对照预设输出 4 张；3 张输入 ×（2 种普通模式 × 2 个画幅 + 4 张壁纸）输出 24 张；空准确文案禁用复制，填写中文后任务逐字保留。
- 复制按钮实测成功，读取浏览器剪贴板确认包含准确中文文案；下载按钮触发任务单下载流程。
- 浏览器控制台未发现 error / warn。桌面实拍封面：`assets/web-preview.png`。
