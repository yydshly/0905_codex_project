# 研究子项目

[返回总索引](../README.md#项目索引)

每个直接子目录对应一个研究项目，采用 `001-project-name` 格式。首页按编号升序生成索引，详细内容在各项目自己的 README 中。

通过仓库根目录的 `node scripts/projects.mjs new` 命令新增项目。模板位于 [`templates/project/`](../templates/project/)，完整用法见[维护指南](../docs/project-guide.md)。

目录编号是稳定引用：不重复、不重排、不回收；完成或停止研究时更新状态，保留目录。各子项目独立选择技术栈、依赖和构建方式。
