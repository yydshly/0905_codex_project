## 实现取舍

- 无依赖静态页面适配已有 Pages 构建契约，避免新增安装步骤。
- 搜索和类别使用组合条件；无匹配时清空详情并提供重置，避免展示过期技能。
- 所有步骤通过按钮明确选择，不自动播放，便于逐项阅读。
- 原生按钮、标签、aria-pressed、动态结果提示与焦点样式支持键盘操作。
- 示例产物、应用建议与源码结论分别标注，不伪装成 Agent 执行记录。
- 动态技能卡片会改变页面高度，初始化后重新定位 URL 锚点，避免刷新落到错误章节。
