# 小规模对照实验方案（尚未执行）

[返回研究概览](../README.md)

## 要回答的问题

增加视觉特征或参考图，是否比只给名称更容易得到符合目标画风、同时服从新主题的图片？

## 固定输入

选择 3 个具有不同线条、色彩和媒介特征的编号，优先选择特征非空且参考图可用的条目。固定主题、画幅、图像模型和用户要求，记录确切模型标识或工具实际返回的信息，未返回字段标为未知。

候选主题：“一个成年人坐在窗边，每天读一页书，窗外有一株小树，画面不含文字。”可以替换为真实研究配图需求。

## 三组输入

| 组别 | 提供的风格信息 |
| --- | --- |
| A | 参考名称＋生图名称 |
| B | A 加条目已有的正向可见特征 |
| C | A 加对应编号单图，声明只用于视觉语言 |

首次 3 个编号各生成 3 组，共 9 张，仅作探索；有明显差异后增加重复样本。比较三条路径属于本研究的对照设计，不是完全照上游能力表选择唯一分支。

## 记录与判断

- 风格匹配：线条、色彩和材质是否接近目标。
- 主题遵循：主体、动作与环境是否符合请求。
- 参考图干扰：是否带入原图主体、文字或构图。
- 制作代价：真实调用、重试、耗时及工具确实提供的费用。

保留全部首次输出、实际提示词和参考图使用记录。建议打乱顺序人工比较，说明标准和主观性。少量样本不能推出 216 种风格的总体成功率。

## 进入下一阶段的条件

真实配图需求出现，或初步实验显示某条路径能减少偏差后，再考虑更多样本、风格推荐入口或与 003、004 的组合。组合时单独处理配色、构图等规则冲突。
