[返回研究概览](../README.md) · [在线体验](https://yydshly.github.io/0905_codex_project/projects/010-handraw-style/) · [验证记录](../notes/web-verification.md)

## 页面内容

- 新增实际样例：三次内置 image_gen 输出，支持大图查看、原始 PNG 下载，附实际提示词和检查记录。图片存在本地，无需再次调用模型。
- 新版以实际风格参考图为入口：默认 12 款跨类别展示，七类筛选、编号／名称搜索、分批浏览全部 216 款、放大和选择。
- 三个场景：文章配图、系列内容、活动主视觉。选中的风格带入任务；可编辑主题、比例与要求，复制包含编号、名称和来源的完整请求。
- 自定义输入拆为主题、要表达的内容、图中必须出现的文字、画幅与其他要求。主题和内容必填；文字留空要求无字图，默认要求不再与可选图中文字冲突。复制的请求明确要求交付实际图片，网页本身仍未接入生图服务。
- 每个场景包含准备内容、目标产出、后续制作、交付检查与四步流程；上方三个固定请求已有实际结果，修改请求仍需重新生成。
- 以下原有解释区保留并折叠，避免盖过效果展示与使用路径。
- 三项能力切换：视觉选型、提示词组织、参考图策略。
- 七类风格目录：范围、条目数量和上游资料入口。
- 四个代表编号的路径演示：默认提示词、名称、特征、参考图与未知模型回退。
- 可编辑主题与可复制 Agent 请求，空输入禁用复制。
- 003、004、005、008 与本项目的对照，以及研究价值、限制和固定源码依据。

页面样图从固定版本的 GitHub Raw 路径按需加载，风格名称从同版本 styles.json 获取；图库不下载重新打包。首次请求失败时保留编号、来源和重试入口；单图失败显示提示。网络故障注入未测试。

上游参考图和场景方案明确区分；本页不调用模型。配置交互是独立演示，未运行上游 Python。模型标识仅表示上游配置键。

## 本地构建与运行

无需安装依赖，使用 Node.js 22+。在仓库根目录运行：

```sh
node scripts/build-site.mjs
node scripts/check-site.mjs
node projects/010-handraw-style/web/preview.mjs
```

打开 [本地网页](http://127.0.0.1:4319/projects/010-handraw-style/)。端口冲突时设置 HANDRAW_PREVIEW_PORT。

仅构建本子项目：`node projects/010-handraw-style/web/build.mjs`。产物位于 web/dist；跨项目导航应使用汇总站点 _site 预览。
