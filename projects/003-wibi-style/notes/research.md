# wibi-style：能力、原理与价值

- 研究日期：2026-09-05。
- 上游：https://github.com/Vieeeeeee/wibi-style

- 作者：@威比 Hunter Wei.（抖音、小红书同名）。
- 方法：核对固定版本 README、文件树，阅读代表性 Skill、规则与脚本；随后使用内置 image_gen 执行 5 次实际生成/编辑，展示 3 个场景。未评测总体成功率或成本。

## 一句话解释

作者提前把风格整理成制作配方；用户选风格并给照片；Agent 读规则、分析照片并组织任务；生图模型实际绘制，必要时由脚本排版或后处理。

Skill 是说明书，Agent 是执行者，图像模型是绘图工具。这里的“风格整理”包括构图、颜色、输入适配、参考素材和验收标准，并非只收集几张图片。仓库本身不训练模型，也不自动上网学习新风格。

## 能力目录

固定版本有 28 个 skills/<slug>/SKILL.md，与 README 的 28 款一致。网页分类为本研究整理，部分风格可以处理不止一种题材。全部名称、调用名、适合输入和来源链接见 ../web/data.mjs。

范围包括人像、儿童、多人合照、宠物、物件、场景、文字创作和局部特写。多数以照片为输入；office-animals 可以由文字指定或随机组合动物、办公室情境、情绪与文案。

## 三条代表性路线

### 电蓝网点：文字规则驱动

输入用户照片，读取 SKILL.md 与 references/style-prompt.md，结合身份、头部角度、表情、毛发明暗与配饰组织编辑要求。图像模型重绘黑白网点主体、电蓝背景和装饰。Agent 再检查身份对应、裁切、三层明暗、网点尺度、背景和输出文件。

证据：https://github.com/Vieeeeeee/wibi-style/blob/b51eff18eed78926e85f3e5602e1f79b220c7925/skills/electric-blue-halftone-poster/SKILL.md

### 框景漫画：先选局部，再做整体

通常先给出三个真实局部候选，用户选择或明确委托 Agent 决定后继续。从随包参考图中选择少量匹配素材，构图卡只负责几何关系，颜色独立选择。先让局部事件成立，再组织小框、大留白、越框和颜色连接。生成后检查，区分局部核心错误和可由版式收尾修正的问题。

1440×2560 PNG 是交付目标；通过缩放达到目标尺寸不代表模型原生生成了等量细节。文中的“蒸馏”指视觉信息提炼，不是模型训练蒸馏。

证据：https://github.com/Vieeeeeee/wibi-style/blob/b51eff18eed78926e85f3e5602e1f79b220c7925/skills/wibi-frame/references/frame.md

验收：https://github.com/Vieeeeeee/wibi-style/blob/b51eff18eed78926e85f3e5602e1f79b220c7925/skills/wibi-frame/references/checks.md

### 复古餐桌：模型生成与脚本收尾

先确定主角、配角、留白与出框关系，按餐桌类型选择风格参考。模型重构复古红底画面，vintage_finish.py 再处理柔化、网点与颗粒等印刷质感。脚本不负责理解菜品，也不是独立生图引擎。

证据：https://github.com/Vieeeeeee/wibi-style/blob/b51eff18eed78926e85f3e5602e1f79b220c7925/skills/retro-table-print/scripts/vintage_finish.py

## 能力边界

- 没有从文件树中发现模型权重或训练实现；不能将这些风格称为该仓库训练的 LoRA，也不能据此推断外部生图模型的网络架构。
- 多数视觉质量门槛由 Agent 按文字规则检查，不是经过量化验证的专用视觉检测器。
- 地下试镜承认转身角度由模型推演，存在五官漂移与右侧完整侧脸命中问题；不能作为真实三视图证据。
- 拼豆挂件展示是视觉结果，不是已验证可生产的图纸；一般生成图片也不等于可编辑矢量文件。
- 上游要求更新检查不发送照片，这不等于整个生图过程离线运行。实际图像处理依赖所用模型与环境。
- 本网页不接入生图 API、不接受上传、不安装 Skill；复制按钮只复制调用示例。交互流程是研究说明。

## 使用场景

适合个人头像、宠物纪念插画、旅行照片再创作、生活记录与设计学习。品牌草案、商业海报和付费服务等用途必须先核实上游商业授权。要求精确人物身份、真实商品细节、固定文字或可编辑源文件的任务，需要额外检查或采用其他工具。

## 对我们与扩展方向（研究建议）

1. 将研究过程封装为“来源核对—能力分析—实验—结论与限制”的原创 Skill。
2. 为研究封面和概念插画积累原创视觉规范；架构、数据和截图继续保持可核对性。
3. 先建立相同照片、普通提示词与完整 Skill 的对照实验，评价身份保留、构图遵循、风格一致性、时间与重做次数。
4. 对尺寸、格式、版式和部分色值增加程序处理；标题与 Logo 等精确排版可与图像生成分离。
5. 在效果评测之后，逐步增加参数、模型能力适配、批量任务与版本记录。

以上是建议，未作为完整系统实现。网页另提供三个已实际生成的样例，见 [实验记录](./generation-experiments.md)。

## 素材与授权

28 款风格图鉴使用固定版本 assets/thumbs/<slug>.jpg 的上游远程展示图，每张标为“上游展示图”，并提供对应 Skill 来源。图鉴展示图不是本研究实测结果，原始照片未取得。新增“实际效果”区使用本次生成的本地文件，两张输入样图与对应编辑输出构成真实调用的前后对照；输入也是 AI 生成，不能称为真实拍摄照片。

未下载和重新打包上游缩略图，未复制运行参考图、完整 Skill 或原始用户照片。图鉴图片网络请求直接访问 GitHub Raw，失败时显示文字降级；本次生成的五个 PNG 则保存在 assets/generated/ 并随构建复制，离线可以浏览这些实际结果。真实本地页面截图用于记录网页布局，来源与图像嵌入边界在 assets/README.md 说明。
