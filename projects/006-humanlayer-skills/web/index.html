04 / READ THE BOUNDARIES

模板是起点，
效果需要验证。

条件标签只是提示结构。 <important if> 帮助表达规则的适用场景，不是程序级条件执行；源码未附指令遵循提升的对照评测。

闭环需要项目自己的检测与验收。 通用模板的 Sensor / Controller 仍有 TODO；建议把验收作为独立 CI 步骤，不只依赖 Agent 自述。

本地调用不能代表所有外部用户。 对公开组件库收紧 Props，还需要考虑已发布的 API 契约和外部调用。

衡量收益，而非生成数量。 扩展时记录问题净减少量、PR 合并率、返工率与成本，再决定是否增加运行频率。
