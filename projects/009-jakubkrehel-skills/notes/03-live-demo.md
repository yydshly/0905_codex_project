# 完整效果演示与验证

日期：2026-09-06。规则来源为上游 commit 267330e1adfc66a718fb65fa6918c1f06d0a689e 的六个 better-* 领域技能，使用其中的部分规则，不声称完成其全部审查流程。

## 实验设计

以“研究项目工作台”为完整交互对象，构建一份基线，使用同一份代码与数据，通过六组规则切换实现优化。初始三条数据来自研究仓库 001、002、009 的 project.json。长标题与 18 项数据是人工构造的压力场景；连接失败也是显式模拟，没有真实后端。

前后共享搜索、收藏、收藏筛选与临时新增项目状态。功能包括查看完整详情、访问上游、添加项目、表单校验、空结果恢复和错误重试。状态只存在于内存，刷新即重置。

## 规则到实现

| 领域 | 实现位置与变化 |
| --- | --- |
| better-layout | preview.css 的 r-layout：移除固定最小宽度、响应式网格、内容分组与间距 |
| better-typography | r-type：标题自然换行、连续字符折行、正文行距与数字层级 |
| better-colors | r-colors：语义颜色变量及明确辅助文字颜色 |
| better-accessibility | r-a11y 和 preview.js：可见输入标签、动作名称、键盘焦点与目标尺寸 |
| better-writing | preview.js 的 writing 分支：明确动作、空状态恢复与错误重试说明 |
| better-ui | r-ui：卡片圆角、层次、0.96 按压反馈与 reduced-motion 条件 |

三个候选方案仅改变密度与对应排版。它们是对 variant 思路的局部实现，不能据此宣称实际执行了完整 variant Skill。

## 测量含义

preview.js 从真实渲染元素读取计算样式。对比度使用 sRGB 相对亮度公式计算，背景是卡片明确声明的不透明纯色；不处理照片或半透明叠层，也不代表整页对比度合格。标题裁剪比较滚动尺寸与可见尺寸；横向溢出比较文档与容器宽度。无卡片时对比度不适用。

本记录没有泛化的性能提升、自动审查准确率或无障碍通过率。浏览器工具日志曾出现一条来源未定位的 MutationObserver 错误；本页源码未使用该 API，所测业务操作均正常，因此不据此声称整个浏览器环境完全无错误。未完成全面读屏、跨浏览器或真实用户测试。
