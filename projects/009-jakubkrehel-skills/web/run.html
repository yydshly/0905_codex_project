EXPLAIN-INTERFACE / MEASURED, DERIVED, INFERRED

首屏的纸卡效果，究竟如何形成？

01 / 实测

底板与网点

.demo-shell 背景为 rgb(233,236,229)。内部 .demo-canvas 使用 radial-gradient，0.7px 点重复在 12px 网格上。

02 / 实测

纸卡与阴影

.specimen 使用 rgb(255,254,249)，阴影 0 12px 26px rgba(38,56,43,.05)。没有图片纹理。

03 / 推导

轻微旋转

浏览器变换矩阵含 -0.0174524；结合源码 rotate(-1deg)，底板与内层整体倾斜约 1°。

04 / 推测

意图与可迁移方法

浅底、细网点、柔和投影和整体倾斜共同产生纸卡感。纸面联想是意图推测；迁移时重调尺寸，不照搬品牌与具体字体。
